# ♟️ JavaScript Chess Engine

A lightweight, interactive chess game built with modern vanilla JavaScript, HTML5, and CSS3. Designed for fast in-browser gameplay with zero heavy external framework dependencies.

👉 **[Live Demo](https://r3han-01.github.io/JavaScript-Chess-Project/)**

---

## ✨ Features

- **Standard Chess Rules:** Complete move validation, turn management, and piece interaction.
- **Board UI & Interaction:** Smooth drag-and-drop or click-to-select move mechanics with clear visual highlights.
- **Zero Dependencies:** Engineered completely from scratch in plain JavaScript to ensure minimal bundle size and lightning-fast loading.
- **Responsive Layout:** Clean, minimalist UI optimized for both desktop and mobile screens.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Hosting:** GitHub Pages
